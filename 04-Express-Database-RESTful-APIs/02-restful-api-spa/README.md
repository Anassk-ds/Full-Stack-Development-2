# Experiment 4(b) - RESTful API Single Page Application

## Aim

To develop a single page application using RESTful APIs.

## Technologies Used

- Node.js
- Express.js
- REST API
- HTML
- CSS
- JavaScript

## Description

This program demonstrates a simple Single Page Application that communicates with an Express.js server using RESTful APIs.

The application allows users to:

- View items
- Add new items
- Delete items
