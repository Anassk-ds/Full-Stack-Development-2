## 🚀 How to Run the Programs

### Node.js / Express.js Programs

Navigate to the required experiment:

```bash
cd 01-Express-Routing-HTTP-Middleware/01-routing
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm start
```

or:

```bash
node index.js
```

---

### React Programs

Navigate to the required React project:

```bash
cd 05-React-Basics/01-render-html
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The exact command may vary depending on the React project setup.

---

### MongoDB Programs

MongoDB programs can be executed using:

* MongoDB Shell (`mongosh`)
* MongoDB Compass
* MongoDB Atlas

MongoDB Atlas can be configured as a cloud-based MongoDB database.
