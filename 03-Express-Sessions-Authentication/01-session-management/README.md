# Experiment 3(a) - Session Management

## Aim

To write a program for session management using cookies and sessions.

## Technologies Used

- Node.js
- Express.js
- Express Session
- JavaScript

## Description

This program demonstrates session management using Express.js and express-session.

The application keeps track of how many times a user visits the page during the session.
