# Experiment 3(b) - User Authentication

## Aim

To write a program for user authentication using Express.js sessions.

## Technologies Used

- Node.js
- Express.js
- Express Session
- Body Parser
- JavaScript

## Description

This program demonstrates a simple session-based authentication system.

It contains:

- Login page
- Username and password verification
- Protected dashboard
- Authentication middleware
- Logout functionality
