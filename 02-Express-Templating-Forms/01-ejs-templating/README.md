# Experiment 2(a) - Express JS Templating

## Aim

To write a program using a templating engine with Express.js.

## Technology Used

- Node.js
- Express.js
- EJS

## Description

This program demonstrates how to use EJS as a templating engine in an Express.js application.

The Express server sends data to an EJS template and the template displays the data dynamically.
