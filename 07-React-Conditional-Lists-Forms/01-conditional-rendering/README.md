# Experiment 7(a) - Conditional Rendering

## Aim

To implement conditional rendering in ReactJS.

## Concept

This program uses `useState` to maintain the login state and the conditional operator to display different content based on whether the user is logged in.

## Run

```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal.

## Output

Before Login:

```text
Conditional Rendering
Please Login
Login
```

After clicking Login:

```text
Conditional Rendering
Welcome User
Logout
```
