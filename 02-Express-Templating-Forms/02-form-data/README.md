# Experiment 2(b) - Express JS Form Data

## Aim

To write a program to work with form data using Express.js.

## Technology Used

- Node.js
- Express.js
- HTML
- JavaScript

## Description

This program demonstrates how to:

- Create an HTML form
- Accept Name and Email
- Submit form data using POST
- Parse URL-encoded form data
- Retrieve submitted values using `req.body`
